# Relação com engenharia de SoftWare
    A arquitetura de software é um subconjunto da Engeharia de SoftWare, assim como a Engenharia Civil tem dentro dela a parte de estruturas

- Engenharia de SoftWare: é o campo mais amplo, que abrange todo o ciclo de vida do software: requsitos, análise, projeto, codificação, testes, manutenção e gestão de projetos 
        -> Como o sistema sera conduzido

- Arquitura de softWare: Foca especificamente na estrutura do sistema e em como ele atende a requisitos de qualidade (escabilidade, seguarnça e etc...)
        -> Define como o sistema será organizado

Exemplos:
    - Engenharia de software: define como será conduzido o projeto: metodologia agil, versionamento no Git, testes autorizados, documentação
    - Arquitetura de Software: define como o sistema será organizado: Monólito ou microsserviços, padrões (MVC, Repository), tecnologias(React, Node, MySql).

Analogia: 
- A engenharia engloba todas as diciplinas necessárias (estrutural, elétrica, hidráulica)
- A arquitetura é o desenho da estrutural principal e como os espaços se organizam
        ou seja, a arquitetura é a parte da engenharia, mas com foco em garantir que o sistema seja bem estruturado e sustentável ao longo do tempo

# Metodologia Cascata 
- Abordagem linear e sequencial 
- Alterações dificeis de implementar
- Feedback limitado do cliente
        -> Requisitos
                -> Desing 
                        -> Implementação 
                                -> Verificação

# Metodologia Ágil 
- Processo iterativo e incremental 
- Adaptação mais fácil à mudanças 
- Feedback continuo do cliente
        Vantagens:
                - Resposta rápida às necessidades 
                - Envolvimento frequente do cliente
